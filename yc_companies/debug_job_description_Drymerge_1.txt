About DryMerge
DryMerge lets users create AI agents that connect to their apps and automate repetitive tasks. These agents adhere to arbitrary user instructions telling them what to do. For example, a user could say "When I get a new demo request on my calendar, enrich the attendee's info, add them as a contact + deal in my CRM, and send me a Slack message with the details". DryMerge spins up an agent that works in the background and automates that task in seconds.
Importantly, DryMerge uses a chat interface instead of a traditional drag-and-drop automation builder. This makes it faster to set up and far more intuitive for non-technical users.
We are a small engineering organization that ships a lot of high-impact code fast.
