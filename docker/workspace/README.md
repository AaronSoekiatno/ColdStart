# AbsurdLangChain Assessment

Welcome to your coding assessment! This workspace contains a LangChain-based application that you'll be working on.

## 🎯 Your Mission

Your task is to implement the required features and ensure all tests pass. Read the mission brief in the `MISSION.md` file for detailed instructions.

## 🧪 Running Tests

To run the test suite and check your progress:

```bash
npm test
```

This will execute all tests and show you which ones are passing or failing.

## 👀 Previewing Your Work

To see your application running:

1. **Start the development server** in the terminal:
   ```bash
   npm run dev
   ```

2. **Access the preview**:
   - Look for the "PORTS" tab in the bottom panel of the IDE
   - Click on port `3000` to open the preview
   - Alternatively, use the "Open Preview" button that appears when the server starts

The app will be available at `http://localhost:3000` within the IDE's preview pane.

## 📝 Important Notes

- All your code changes are automatically tracked via git commits
- Focus on making the tests pass - that's how your work will be evaluated
- You have access to Claude Code AI assistant - use the `claude` command in the terminal
- The dev server is for previewing your work; final scoring is based on test results

You can get AI assistance by running:

```bash

```

```bash

```

## 📂 Project Structure

- `app/` - Next.js application code
- `tests/` - Test files (your goal is to make these pass!)
- `lib/` - Utility functions and helpers
- `components/` - React components

## ✅ Submission

Your work is automatically saved and tracked. When you're done:
1. Make sure all tests pass by running `npm test`
