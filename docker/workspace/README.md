# Assessment Workspace

Welcome! Your environment is fully pre-configured.

## 🚀 Quick Start

1. **Preview App**: The development server is **already running**. Click the "Open Preview" button or check the **Ports** tab (Port 3000).
2. **Run Tests**: Validation is key.
   ```bash
   npm test
   ```
3. **AI Assistant**: Claude is available in the terminal.
   ```bash
   claude
   ```

## 🎯 Important
- **Focus on Tests**: Your score is based on passing tests in `tests/`.
- **Auto-Save**: Components are auto-saved.
- **Submission**: Click the "Submit" button in the top bar when finished.

Good luck!
